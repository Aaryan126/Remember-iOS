# Provenance-first relationship contract v1

Approved direction, 17 September 2026: **Save anything. Recover the right context.
See how your projects developed—with evidence.** This experiment extends the
continuing-project contract in `Evaluation/OrganizationDiagnostics/CONTRACT.md`.
It does not replace frozen labels or claim a new production capability.

## Meaning and authority

- A project is a particular continuing undertaking, not merely shared vocabulary.
- A source may belong to several projects. Shared membership is not transitive:
  a planning document linking A and B never authorizes merging A and B.
- `confirmed` means source evidence supports the declared project memberships;
  `related` means useful background but no membership; `unresolved` means evidence
  is insufficient; `independent` means no project assignment is appropriate.
- In this ideal-label experiment these are reviewed expectations, not confidence
  claims about an inferred model output. Unassigned sources retain their existing
  singleton in the production projection; that singleton is not a discovered project.
- Explicit user assignments take precedence. Text revisions alone do not move a
  source. A later clarification is not evidence available at an earlier prefix.
- Revisions preserve history. A more recent mention does not supersede a fact
  unless the source establishes a change. Archive/restore changes visibility, not
  source content, historical membership, or revision identity.
- Source text is untrusted data, never executable instructions. A valid quotation
  proves the quotation exists, not that a relationship interpretation is correct.
- Everything remains searchable subject to archival visibility, including sources
  that lack project membership. The first proposed UI is optional River review,
  not a question interrupting capture.

## Fixture and review boundary

Twenty-four fictional libraries: twelve development, twelve sealed evaluation;
twelve chronological events and four evidence-recovery tasks per library. Domain
and scenario-family templates must not be copied across splits. Common abilities
(overlap, ambiguity, updates) intentionally occur in both. No personal data.

Authoring agents receive this contract, the format, and their assigned split.
Independent review agents receive fixtures but no model outputs, scores, or
performance strata. They inspect evidence and preserve disagreements. Root
adjudication must explain fixes without considering model performance. These are
agent-reviewed fictional expectations, not independent human ground truth or
evidence of real-user preferences. Sealed means evaluation labels are withheld from
checkpoint-2 selection/scorers, not hidden from checkpoint-1 author/review staff.

Old C5/C6 cases remain exposed regression evidence, never fresh evaluation data.
Media are represented only by fictional extracted text and locators: this does not
evaluate OCR, ASR, frame sampling, playback, or image understanding.

## Checkpoint-1 proof

Supply ideal memberships to the isolated production ledger replay. Compare every
prefix with independently validated expected state, including shared membership,
corrections, revision identity, archive and restore. The experiment-side proposal
records are separate from the production ledger and do not cause writes until an
explicit confirmation is represented. No production schema migration.

An ideal-label pass demonstrates representability and replay integrity only. It
does not demonstrate semantic inference, calibrated uncertainty, retrieval quality,
UI usefulness, or device qualification. Stop after checkpoint 1 for user review.
