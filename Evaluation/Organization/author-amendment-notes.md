# Author amendment proposal

This file is author-only context. The proposal in `amendments.json` is a delta against the exact SHA-256 recorded in `baseInputsSHA256`; it does not modify the existing inputs, author labels, or independent reviews. There are exactly two replacements per library: one sparse capture of 6–14 whitespace-delimited words and one longer capture of 180–260 words. The selected sources are distinct single-membership primary-context items, never bridges or unrelated singletons. The two replacements in each library also originate in different primary contexts.

The original short corpus did not adequately vary capture length. These changes introduce terse reminders with partial names or referents, and longer notes that mix observations, practical reasoning, and next actions within an existing context. Long versions develop the fictional source's original subject rather than introducing a second project. No replacement instructs the organizer to keep two benchmark contexts separate. The Spanish/English and French/English libraries retain substantive multilingual text. No private assets, application predictions, or results informed the replacements.

The proposed sparse finder reminder in l10 deliberately omits the telescope name; the rest of that library supplies relevant evidence, but an independent reviewer may judge its identity less certain. Similar shorthand in the swatch, footwork, and drip-line reminders is intentional. The author proposes retaining the original memberships, subject to blind delta review. Existing rationales that quote replaced text will need evidence updates if the proposal is accepted; the proposal itself includes no gold memberships or rationale fields.

These amendments are not applied by the author. The coordinating agent should preserve original review artifacts, collect independent source-based delta judgments, adjudicate uncertainty, then apply the accepted replacements and recompute dataset/review hashes before any predictions. The original `author_corpus.py` now refuses to run if either output artifact already exists. In a fresh output directory it generates the pre-amendment text, so accepted deltas must remain part of the versioned reproduction procedure.
