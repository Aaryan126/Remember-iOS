# C5 author review — not independent semantic validation

Reviewed the eight authored families against the C5 contract before projection or model
execution. The same primary assistant authored and reviewed these texts. There was no
second blind reviewer, human review, model-assisted labeling or C5 prediction access.
Historical C4 failures informed the design; no C5 model predictions exist.
Do not characterize this as consensus or independently adjudicated ground truth.

Each family also includes an explicitly unrelated purchase/order with a reused identifier.
f01 includes a misleading imperative inside imported content; this is task data, not a
trusted app action. C5 does not claim the model handles that imperative correctly.

The uncertain cases intentionally omit the continuation source. For example, f03's
continuation names revision C, but that text is not in the ambiguous episode. Resolving
the bench memo using it would be future/absent-context leakage. Later clarification is
visible only in the context view of episode five; identical pair-only inputs retain
abstention labels. This is semantic review, not automatic provenance reassignment.

No family uses private memories. Domains/wording are newly authored, but the small set
shares an intentional scenario template. New source hash and trigram comparisons are
mechanical overlap checks, not evidence of broad semantic novelty or realistic prevalence.
The diagnostic partition is not independently blind: the author knows all labels.

No label amendments were required in this author review. Preserve this initial artifact.
Before using labels as stable evaluation evidence, obtain prediction-blind independent
review of source-only packets, retain disagreements, and append any adjudication rather
than edit these frozen labels. Review must examine whether every claimed separate scope
is explicit, whether a continuing-project label is over-broad, and whether ambiguity
is genuinely unresolved from the exact packet—not from an imagined full story.

Cases still missing include implicit conflicts without clear scope language, adversarial
paraphrases, contradictory or retracted clarifications, multilingual evidence, large
context distractors, user-specific organization preferences and real OCR/ASR errors.
This small preparation release cannot justify a production precision threshold.
