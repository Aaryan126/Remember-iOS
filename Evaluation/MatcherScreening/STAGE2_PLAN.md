## Implementation details fixed before results

- Identifier tokens: ASCII alphanumeric components with internal hyphens, containing either a letter and digit or an internal hyphen; case-sensitive; pure dates/times are excluded by requiring a letter. Strip possessive suffixes. Hyphenated words are clues, not guaranteed identifiers. Features: Jaccard, both-present/disjoint, either-missing, both-missing. Never use source record IDs as text features.
- B features: absolute vector differences and elementwise products, separately for the existing contextual and sentence spaces, followed by the six baseline features and four identifier features. Fit StandardScaler on known fitting pairs only. MLPs use batches of 64, 20 epochs, the proposed optimizer/dropout/settings and deterministic epoch shuffles.
- C: binary class order not-same/same; pair directions appear twice with equal weight. Three epochs, effective batch16/microbatch8, unweighted cross-entropy, AdamW, 10% linear warmup then linear decay. Head LR0.001; backbone settings exactly as proposed. C1 freezes BERT and keeps its encoder in eval mode, with classifier-side dropout active during training. C2 freezes everything except the final two transformer layers and classifier; C3 trains all parameters. The pooler is frozen in C1/C2. Evaluate both directions and average probabilities. Use dynamic padding without truncation beyond the fixed512 maximum.
- Save only trainable tensors plus immutable base/config bindings, losslessly compressed. Full-backbone candidates therefore still preserve all trained weights. No lossy precision reduction. Final fit models, including hybrid inner fits, remain retained.
- Reuse identical C fits between standalone and hybrid models. Inner hybrid scores are generated by a model that never fitted the scored library; combiner preprocessing and fitting use the outer fitting libraries only.
- Screen ranking: qualifying-calibration-fold count, pooled macro recall, precision, lower family complexity A/B/C/D, then trial ID. If every candidate has zero qualifying folds, use pooled same-match AP only as a research-lead fallback. Choose the best trial in each family, then at most two families. Selection is saved before opening development for confirmation.
- Confirmation: selected trials fit all18 training libraries and calibrate/report on the six already-inspected development libraries. Deterministic simple models run once; stochastic models use seeds17/29/41. A hybrid uses three inner training-library folds (fit12/score6) for its combiner, then a base refit on18. Shared base fits are reused. Report every seed; do not pick the lucky seed. A stochastic family is robustly qualifying only if every seed meets the proposed precision/count/recall-gain/precision-drop gates against the previously frozen development baseline. This is exploratory confirmation, not a fresh reliability claim.
